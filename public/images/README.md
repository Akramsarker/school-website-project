# ওয়েবসাইট ইমেজ ফোল্ডার

প্রতিটি সেকশনের ছবি **নিজের ফোল্ডারে** রাখুন। ফাইলের নাম সহজ ও সংখ্যাযুক্ত রাখলে ম্যানেজ করা সহজ হয়।

## ফোল্ডার তালিকা

| ফোল্ডার | হোম পেজ সেকশন | উদাহরণ ফাইল |
|---------|----------------|-------------|
| `hero/` | হিরো (উপরের ব্যানার) | `hero-banner.jpg` |
| `principal/` | প্রধান শিক্ষকের বাণী | `principal.jpg` ✅ |
| `achievements/` | সাফল্য ও সম্মান | `award-1.jpg`, `sports-trophy.jpg` |
| `history/` | ইতিহাস টাইমলাইন | `history-1975.jpg`, `history-2025.jpg` |
| `alumni/` | বিশিষ্ট প্রাক্তন শিক্ষার্থী | `alumni-1.jpg`, `alumni-2.jpg` |
| `schedule/` | অনুষ্ঠান সময়সূচী | `event-rally.jpg`, `event-cultural.jpg` |
| `notices/` | নোটিশ বোর্ড | `notice-jubilee.jpg` |
| `gallery/` | গ্যালারি পেজ | `gallery-1.jpg` … `gallery-8.jpg` |
| `contact/` | যোগাযোগ পেজ | `campus-map.jpg`, `school-gate.jpg` |

## ছবি যোগ করার নিয়ম

1. উপযুক্ত ফোল্ডারে `.jpg` বা `.webp` ফাইল কপি করুন।
2. `data/alumni.json` বা `data/gallery.json`-এ পাথ আপডেট করুন (প্রয়োজন হলে)।
3. প্রধান শিক্ষকের ছবি: `principal/principal.jpg` (ইতিমধ্যে সেট করা)।

## সুপারিশকৃত সাইজ

- **প্রধান শিক্ষক / প্রাক্তন:** ৮০০×৮০০ px (বর্গাকার)
- **গ্যালারি:** ১২০০×৮০০ px বা তার বেশি
- **হিরো / ইভেন্ট:** ১৯২০×১০৮০ px (ওয়াইড)

প্রতিটি সাব-ফোল্ডারে আরও বিস্তারিত নির্দেশনা আছে।
