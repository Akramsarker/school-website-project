# প্রাক্তন শিক্ষার্থী (`#alumni`)

এখানে প্রাক্তনদের প্রোফাইল ছবি রাখুন।

## ফাইল নাম

```
alumni-1.jpg
alumni-2.jpg
alumni-3.jpg
...
```

## ডেটা ফাইল

`data/alumni.json`-এ পাথ এভাবে দিন:

```json
"photo": "/images/alumni/alumni-1.jpg"
```

নতুন প্রাক্তন যোগ করলে পরের নম্বর ব্যবহার করুন (যেমন `alumni-6.jpg`)।
